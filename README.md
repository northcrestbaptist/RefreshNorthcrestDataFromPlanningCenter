# RefreshNorthcrestDataFromPlanningCenter

## Northcrest Baptist Church Web Supporting Services
This is the code repository for the .NET Core applications and services that support the Northcrest Baptist Church Web Application.

# Includes the following:
- RefreshNorthcrestDataFromPlanningCenter
- NorthcrestWebService

# RefreshNorthcrestDataFromPlanningCenter
This includes three projects that are used to build an application that refreshes the NBC database from updated Planning Center data.  This application is staged on the server where the database is housed.  Then, the Windows Task Scheduler is configured to execute this application periodically throughout the week.

# NorthcrestWebService
This includes all of the web services that are used to add, update, and retrieve data for the Northcrest Baptist Church Web Application.
